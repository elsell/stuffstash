# Native complete print-flow acceptance

The earlier printing audit covered label downloads and settings, but did not cover
AssetPrintScreen, QuickPrintScreen, PrintJobScreen or uncertain-job controls.
A focused `printing-complete-flow` native audit must exercise those production
components on named iPhone and iPad simulators at normal and accessibility text.
Use the native task header and the production asset-print add-sheet presentation,
with a real return screen. Reprint keeps its stack route and native Cancel. Preserve native Cancel, the iOS Copies stepper, scrolling and footer reachability.
Assert the edited value and full preview containment within the sheet scroll area.
Scroll the viewport containing the target control, never an underlying screen.
Repository fakes must declare port return types rather than narrower inferred buffers.

The quick-print entry first encounters a controlled preview failure and falls back
to options. Verify a visible failed manual preview, then recover a real PNG. Fetch
its bytes through the production generated SDK and ApiPrintingRepository using
actual Expo fetch against a loopback HTTP peer. Write through ExpoLabelFiles and
verify native image decoding; a data URI or fake local file must not stand in for
this binary path. The peer serves a catalog-rendered sample and ordinary scoped
provision/render/content envelopes; it never contacts production or hardware.

Queue exactly the edited synthetic copy count, inspect queued status, cancel that
job, then reprint as a distinct job. Separately inspect an idle-confirmed uncertain
job, choose an outcome and explicitly acknowledge uncertainty before resolving.
Do not silently treat acknowledgement as physical completion. Stateful repository
fakes own synthetic jobs and revision changes; the real submission use case owns
idempotency. No fixture request may escape to a real printer or production API.

Fixture tests guard route installation and real HTTP peer behavior. Native captures
must identify source and device; source checks alone do not establish native UI,
binary delivery or image rendering. This audit does not verify real OIDC, backend
authorization, physical printing, camera decoding, system sharing recipients or
VoiceOver. Record failed stages honestly and retain the existing bounded native
investigation budget.
