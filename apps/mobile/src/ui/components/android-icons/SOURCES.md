# Android icon sources

The icons below use filled Material contours from Google’s material-design-icons
repository at revision `40a7a292a79d9394157e1ea24f83d52d5e17c556`, under the adjacent Apache2.0 license.
SVG paths were copied into Android XML; transparent canvas paths were omitted.
Filled contours are required because Expo UI55.0.17 ignores vector strokes.
